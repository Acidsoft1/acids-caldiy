# AcidSoft brand assets (public)

Публічні бренд-ассети для теми `acidsoft-theme` цього форку. Секретів тут немає і бути не може — форк публічний.

| Файл | Джерело |
|---|---|
| `icons/favicon.svg` | оригінал `https://acidsoft.io/favicon.svg?v=2` (2026-09-28), без змін |
| `icons/favicon-16x16.png`, `favicon-32x32.png`, `favicon.ico` | растр з `favicon.svg`, прозоре тло, без розтягування |
| `icons/apple-touch-icon.png` (180), `android-chrome-192x192.png`, `android-chrome-512x512.png` | растр з `favicon.svg`, поля, тло `#05050d` |
| `fonts/orbitron-latin.woff2` | Orbitron, variable wght 400–900, Google Fonts, SIL OFL 1.1 (`OFL-Orbitron.txt`) |
| `fonts/inter-*.woff2` | Inter, variable wght 300–700, subsets latin/latin-ext/cyrillic/cyrillic-ext, SIL OFL 1.1 (`OFL-Inter.txt`) |

Палітра й шрифти відтворюють живий acidsoft.io (CSS `:root` станом на 2026-09-28). Джерело рішення — `acids-infra/openspec/changes/customize-caldiy-design`.
